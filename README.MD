# Pacekable

Pacekable is a beautiful collection of ready-to-use blocks for Gutenberg - the new WordPress editor. Pacekable's blocks gives you the capability to build awesome front pages and landing pages.

## Philosophy

Pacekable aim is simple – to provide useful and beautiful **blocks for everyone**.

Everyone should enjoy free and ready access to a full set of blocks to make page building as simple and straightforward as possible.

## Getting Started

1. Clone or download this repo in `wp-content/plugins` in your WordPress development environment.
2. Install the dependencies via `npm install`
3. Activate the Pacekable in your local WordPress site
4. Watch for file changes via `npm run start`
